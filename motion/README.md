# 2부 종이 연출

`viewer-motion.js`와 `viewer-motion.css`는 `index.html`의 2부 `motionPlan`을 재생합니다. 67컷에 대본 포인트 257개를 연결했고, 화면에 있는 인물의 대사 시작 19곳에 한 번 들썩이는 동작을 넣었습니다. 1부 대본·영상·배치 데이터는 유지했습니다.

## 재생

- 처음 열면 현재 컷을 자동 반복합니다. 일시정지 또는 슬라이더 탐색 후에는 재생 버튼으로 다시 시작합니다.
- `카메라 적용`은 풀샷에서 약간 확대하여 매우 천천히 팬·틸트·줌을 진행합니다. `고정 프레임`은 원래 촬영판 좌표를 보여 줍니다. 선택은 해당 브라우저에 보관합니다.
- 종이 동작은 순서대로 진행합니다. 책에 붙은 페이지나 인물이 든 책만 함께 움직여 최대 두 장이 됩니다. 카메라는 종이 동작 중 정지합니다.
- 각 컷의 끝에서 짧게 화면을 페이드하고 시작 배치로 돌아갑니다. 시간은 한국어 대본 길이를 기준으로 잡은 연출 미리보기이며 녹음 파일에 맞춘 타임코드는 아닙니다.

## 출력 크기

1부 `JPG 출력`, `png 추출/02_캐릭터`, `png 추출/03_소품`의 36개 이미지를 확인했습니다. A3 출력 원본은 4961 × 3508px, 300dpi이며 화면에는 4961 × 2792px의 16:9 촬영판을 기준으로 배치합니다. 기존 추출 그림은 종이의 픽셀 치수를 유지합니다. 새 시안은 1부 인물·소품과 비교해 고정 치수를 제안합니다.

`part2PrintSpecs`의 규격 ID를 모든 컷이 공유합니다. 종이 이동과 카메라 변환은 규격을 바꾸지 않습니다. 인물 전신, 과거 모습 카드, 세부 파츠는 각각 별도의 준비물·규격입니다. 가공 시안의 치수는 최종 인쇄 전에 확인할 제안값입니다.

| 별도 준비물 | 용도 | 제안 규격 |
| --- | --- | --- |
| `PR-P02-S11-C02-03-01` 일본어 일기_휴대용 | 치코링이 가슴에 드는 장면 | 약 50.4 × 33.4mm |
| `PR-P02-S08-C01-01` 실린더_확대 | 수리·손 확대·마지막 재생 인서트 | 일반 실린더 폭의 2배, 약 130.2mm |
| `CHC001-05` ~ `CHC001-08` 시민_분절01~04 | 네 조각을 각각 진입·퇴장 | 원본 미리보기의 공통 축척 유지 |

휴대용 일기·확대 실린더·시민 네 조각의 준비 상태는 `가공 필요`입니다. 기존 일기 확대판 `PR011`과 일반 실린더 `PR031`은 별도 규격으로 유지합니다.

`citizen-01.svg` ~ `citizen-04.svg`는 사용자가 지정한 `분절/시민 배치 미리보기` JPG 네 장의 흰 배경을 투명하게 표시한 시안입니다. 조각 사이 비율을 유지하며, 원본 파일은 변경하지 않았습니다. `paper-*.svg`는 기존 1부 두루마리·메모 비율을 참고한 설명용 도식입니다. 최종 출력물로 간주하지 않습니다.

현재 G7 출력 시트는 기존 추출본과 배치·회전·반전이 다르지만, 이리스 1611 × 2227px와 히스이 1166 × 2034px의 종이 규격이 같음을 대조했습니다. 1부 추출본은 유지합니다. 확인한 출처와 치수는 `part2ScaleReferences`에 기록했습니다.

## 검증

전체 67컷의 시작·중간·끝과 각 이벤트 경계를 포함한 1,105개 상태에서 좌표·타깃·규격 일치, 동작 최대 두 장, 종이 동작 중 카메라 정지를 확인했습니다. 391개 렌더링 프레임의 연결 검사와 67컷 구도 검토, 실제 브라우저에서 자동 반복·일시정지·슬라이더·고정 프레임 전환을 확인했습니다. 한국어·일본어 대본은 유지했습니다.
