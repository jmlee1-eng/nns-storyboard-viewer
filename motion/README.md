# 2부 종이 연출

`viewer-motion.js`와 `viewer-motion.css`는 `index.html`의 `motionPlan`을 재생합니다. 사용자 컷별 수정 후 2부 64컷과 통합본 에필로그 4컷에 적용합니다. 1부 대본·영상·배치 데이터는 유지했습니다.

## 컷별 수정

S04 C04+C05, S05 C01+C02, S10 C01+C02, S15 C01+C02, S19 C04+C05를 각각 병합하고 S23 C02를 삭제했습니다. S06 C03은 전신/손 인서트/작별의 C03–C05로, S18 C01은 대사와 도시 정지 인서트로 분리했습니다. 번호가 달라진 컷에는 수정 전 번호를 표시하고 삭제된 내부 링크는 병합된 컷으로 연결합니다.

이름표는 처음에 숨기고 인물의 진입·겉종이 벗김이 끝난 뒤 순서대로 넣습니다. 모브 동료는 얼굴 없는 괴로운 모습의 한 장 묶음으로 다시 그렸으며, 같은 윤곽의 검은 뒷종이를 겉종이 아래에 둡니다. 실제 종이 찢기는 한 장을 두 조각으로 나누는 SVG 미리보기이며 같은 출력 규격을 공유합니다. 실제 촬영에서는 원본 종이 한 장을 찢습니다.

축음기 상태는 닫힘, 열림/실린더 없음, 열림/실린더 삽입/태엽 없음, 열림/실린더 삽입/태엽 있음의 네 그림입니다. 실린더·상자·뚜껑·작은 나팔·태엽의 분리 그림도 세트 준비물에 연결했습니다. S16 C01의 일기에는 시간축에 따른 넘김과 이전/다음 페이지 조작이 있습니다. 사용자가 페이지를 넘기면 재생이 멈춥니다.

새 작화·합성 도안은 `screen-assets/revision-20261119/`에 있습니다. 모브·한쪽 가시 줄기·맞잡은 손·축음기·흙과 자갈 방벽·검은 유리구슬·표정 클로즈업·정원·꽃 없는 배경은 built-in image_gen으로 만들었습니다. 계약서는 새 양피지 그림 위에 정확한 조항 글자를 SVG로 넣었으며 마지막 조항은 `해약`으로 시작합니다. 상태·분절·텍스트 도안은 최종 재단·출력 확인이 필요한 시안입니다.

## 재생

- 처음 열면 현재 컷을 자동 반복합니다. 일시정지 또는 슬라이더 탐색 후에는 재생 버튼으로 다시 시작합니다.
- `카메라 적용`은 풀샷에서 약간 확대하여 매우 천천히 팬·틸트·줌을 진행합니다. `고정 프레임`은 원래 촬영판 좌표를 보여 줍니다. 선택은 해당 브라우저에 보관합니다.
- 종이 동작은 순서대로 진행합니다. 책에 붙은 페이지나 인물이 든 책만 함께 움직여 최대 두 장이 됩니다. 카메라는 종이 동작 중 정지합니다.
- 각 컷의 끝에서 짧게 화면을 페이드하고 시작 배치로 돌아갑니다. 시간은 한국어 대본 길이를 기준으로 잡은 연출 미리보기이며 녹음 파일에 맞춘 타임코드는 아닙니다.

## 출력 크기

1부 `JPG 출력`, `png 추출/02_캐릭터`, `png 추출/03_소품`의 36개 이미지를 확인했습니다. A3 출력 원본은 4961 × 3508px, 300dpi이며 화면에는 4961 × 2792px의 16:9 촬영판을 기준으로 배치합니다. 기존 추출 그림은 종이의 픽셀 치수를 유지합니다. 새 시안은 1부 인물·소품과 비교해 고정 치수를 제안합니다.

`part2PrintSpecs`의 규격 ID를 모든 컷이 공유합니다. 종이 이동과 카메라 변환은 규격을 바꾸지 않습니다. 인물 전신, 과거 모습 카드, 세부 파츠는 각각 별도의 준비물·규격입니다. 가공 시안의 치수는 최종 인쇄 전에 확인할 제안값입니다.

| 별도 준비물 | 용도 | 제안 규격 |
| --- | --- | --- |
| `PR-P02-S11-C02-03-01` 일본어 일기_휴대용 | 치코링이 가슴에 드는 장면 | 약 50.4 × 33.4mm |
| `PR-REC-01` 실린더 축음기 5부품 세트 | 수리·이동·마지막 재생 | 네 조립 상태의 공통 축척, 다섯 분절 부품 연결 |
| `CHC001-05` ~ `CHC001-08` 시민_분절01~04 | 네 조각을 각각 진입·퇴장 | Group 7의 작은 시민 크기 기준, 네 묶음 유지 |

휴대용 일기·새 축음기·시민 네 조각의 준비 상태는 `가공 필요`입니다. 기존 일기 확대판 `PR011`은 별도 규격으로 유지합니다. 이전 일반/확대 실린더 제안은 자료에 남겨 두고 현재 2부에서는 새 축음기 세트를 사용합니다.

`citizen-01.svg` ~ `citizen-04.svg`는 사용자가 지정한 `분절/시민 배치 미리보기` JPG 네 장의 흰 배경을 투명하게 표시한 시안입니다. 조각 사이 비율을 유지하며, 원본 파일은 변경하지 않았습니다. `paper-*.svg`는 기존 1부 두루마리·메모 비율을 참고한 설명용 도식입니다. 최종 출력물로 간주하지 않습니다.

시민 크기는 `png 추출/02_캐릭터/Group 7 이리스 반전 시민 아웃라인.png`의 작은 시민 본체를 기준으로 보정했습니다. 오른쪽 위 큰 단독 시민은 제외했습니다. JPG 배치 미리보기 1px를 원본 출력 시트 2px로 환산하여 기존 네 묶음과 중심 좌표·동작을 유지한 채 크기만 약 64.8%로 줄였습니다. 분절별 제안 치수는 01: 42.0 × 38.9mm, 02: 56.4 × 56.0mm, 03: 35.6 × 65.0mm, 04: 78.4 × 74.3mm입니다.

현재 G7 출력 시트는 기존 추출본과 배치·회전·반전이 다르지만, 이리스 1611 × 2227px와 히스이 1166 × 2034px의 종이 규격이 같음을 대조했습니다. 1부 추출본은 유지합니다. 확인한 출처와 치수는 `part2ScaleReferences`에 기록했습니다.

## 검증

2부와 에필로그 68컷의 시작·중간·끝과 이벤트 경계에서 타깃·출력 규격, 동작 최대 두 장, 종이 동작 중 카메라 정지, 보이지 않는 인물의 대사 동작 및 이름표 선등장을 검사했습니다. 컷별 요청 47개를 별도 대조하고 전체 구도를 검토했습니다. 실제 브라우저에서 슬라이더·카메라 전환·일기 페이지 넘김을 확인했습니다. 사용자 변경 대본은 KR/JP 양쪽에 반영했습니다.
