# NNS 촬영 뷰어 (보기 전용)

NNS 대본·화면 구성·준비물 뷰어의 정적 사본입니다. 편집 저장 기능은 없습니다.

- 뷰어: `index.html`
- 통합본 영상: [1부·2부·에필로그](video/combined/) (119컷, 44분 45초, 한국어·일본어 음성, 자막·컷 타임코드)
- 1부 영상: `video/part1/` (씬별 파일 18개를 이어서 재생, 720p, 한국어·일본어 나레이션 선택)
- 2부 영상: `video/part2/` (61컷, 약 20분 49초, 씬별 25개 파일, 720p, 한국어·일본어 음성 선택)
- 에필로그 영상: `video/epilogue/` (4컷, 약 2분 53초, 씬별 3개 파일, 720p, 한국어·일본어 합성 나레이션 선택)
- 영상 페이지에서 한국어·일본어 오디오 트랙을 담은 전체 MP4와 자막·컷 타임코드를 내려받을 수 있습니다.
- 전체 대본: `script/`
- 배경·초기 배치별 촬영 순서: [2부 촬영 순서](shooting/part2/)
- 2부 단독본은 61컷입니다. 벨–메이와 치사–뮤게 장면은 통합본에서 볼 수 있으며, 도입 하이라이트는 두 판본에서 제외했습니다.

2부 자막은 한·일 문장 종결점에서 전환합니다. 2부와 통합본의 추가 대사 및 첫 음절 보정 구간은 기존 캐릭터별 ElevenLabs 한·일 음성으로 갱신했습니다. S21 C01은 등록된 꽃잎 방벽 FX048을 미리보기에 연결했으며, 실물 촬영용 A3 출력판 배치가 필요합니다. S05 C01과 S06 C03은 한 테이크를 두 컷으로 편집하며, S07 C01과 S08 C01은 주군과 소품 배치를 이어서 사용합니다.

2부 화면은 자동 반복 재생됩니다. 연출 진행 슬라이더로 원하는 프레임을 확인하고, `카메라 적용` 버튼으로 느린 카메라 움직임과 고정 프레임을 전환할 수 있습니다. 종이 동작은 한 번에 하나를 기본으로 하고 최대 두 장까지 움직이며, 동작 중에는 카메라를 멈춥니다. 해당 컷의 동작표에 따라 대사 시작에 인물을 한 번 들썩입니다. 재생 시간은 대본 포인트 기준 미리보기입니다.

동일 준비물은 같은 출력 크기를 사용합니다. 1부 출력 이미지 36개를 기준으로 비율을 맞췄고, 손·이리스 표정 클로즈업은 별도 준비물로 등록했습니다. 2부 이름표는 처음 소개하는 인물만 사용하며, 1부에서 소개한 인물은 반복하지 않습니다. 시민은 필요한 컷에서 네 조각으로 진입·퇴장합니다. 새 축음기는 다섯 분리 부품과 네 조립 상태를 확인할 수 있으며, S16 C01에서는 이전/다음 페이지 버튼으로 일기를 넘길 수 있습니다. 컷별 출력 규격과 연출 포인트는 화면 아래에서 펼쳐 볼 수 있습니다. 구현과 규격 기준은 [motion/README.md](motion/README.md)를 참고하세요.

축음기·모브·가시 줄기·공통 계약서는 [화풍 수정본](screen-assets/style-20261119/README.md)으로 갱신했습니다. 축음기는 둥근 완전 분리형 덮개, 계약서는 위쪽 봉과 손글씨 본문 및 마지막 `解約` 조항을 사용합니다. 배경 가공 시안은 활성 컷에서 제외하고 공식 게임 원본으로 교체했습니다. 대본 배경명과 등록 주소가 다른 부분은 [원본 검증표](motion/background-source-review.md)에 구분했습니다. [뮤게 추가 장면](motion/muguet-introduction-proposal.md)은 S12의 이리스와 설계 보고, S15의 코어 입구 대화 두 컷, S23의 마지막 선택 보강으로 반영했습니다.

2부 화면은 실제 출력물, 가공 시안, 배치 설명용 도식을 구분합니다. 시안·도식이 보이는 항목도 기존 준비 상태를 따르며, 인쇄용 최종 파일이 아닙니다. 표시용 경량 이미지는 `screen-assets/`에 있습니다.

원본은 로컬 뷰어 서버에서 `build_site.py`로 생성합니다. 이 저장소의 2부 연출 데이터는 `index.html`에, 재생기는 `motion/`에 있습니다. 원본 생성기로 다시 만들 때는 이 연출 데이터와 재생기 연결을 함께 보존해야 합니다.

쿠로코의 방벽은 [목제 이동 방벽 앞·뒷면](screen-assets/wooden-wall-20261120/README.md)으로 갱신했습니다. 2.5주년의 목공·못질 설정에 맞춘 좁고 높은 형태이며 P2-S13 C01 및 준비물 목록에 반영했습니다.

2026-11-20 준비물 목록을 열린 PSB와 대조했습니다. 1부 재활용, PSB 배치 확인, 추가 배치, 가공·규격 확인을 준비 상태 아래에서 구분하고, 리소스 창에서 대응 레이어를 확인할 수 있습니다. 같은 그림·같은 출력 크기의 역할별 중복은 통합하고 크기가 다른 준비물은 유지했습니다. PSB 배치 확인은 실물 인쇄 완료와 구분합니다. 컷 대본과 화면 배치는 바꾸지 않았습니다.

2026-11-23 2부 `레오나_평상복`은 1부에서 사용한 `CHA004-03 레오나` 출력물을 재사용하도록 통합했습니다. P02-S25-C01·P02-S27-C01과 통합본에서 기존 그림·기본 표정·출력 크기를 그대로 사용하며, 같은 그림을 사용하며 준비 상태는 최신 재출력 지시에 따라 출력 필요로 표시합니다.

S21 C04의 대본을 수정하고 S22 C01에는 치코링의 일기와 다섯 소녀의 마지막 대사를, S23 C01에는 힘을 내려놓는 흐름과 뮤게의 대사를 모았습니다. S24 C01+C02는 한 컷으로 합쳤습니다. 주군·공통 원본·와카와 타마의 진입 및 대사, 세 인물 퇴장, 소형 계약서 여섯 장의 원본 위치→주변 이동, 공통 원본→여섯 계약서 순차 찢기, 라르므 겉그림 걷기→흰 뒷종이 유지→마지막 퇴장을 재생합니다. KR/JP 전체 대본도 같은 구성입니다.

준비물 목록은 Office PC의 `A3 사이즈 출력 정리_2부.psb` 실제 에셋 57개와 내부 부품을 기준으로 갱신했습니다. 에셋·그룹·부품 레이어 이름 112개를 실제 준비물 ID·이름으로 정리했고, [PSB 대조표](preparation/psb-20261123/index.html)에 113개 준비 항목의 대응 레이어와 남은 작업을 기록했습니다. 1부 기출력은 누락에서 제외하며, FX025·FX036·FX041·FX048·FX052·FX054는 사용자 지정에 따라 미출력·연출 재검토 대기로 구분합니다. 현재 대본과 연출 배치는 유지했습니다.

준비물 표에는 기존 출력물과 가공 전 소스 이미지를 텍스트 높이의 작은 미리보기로 표시하며, 마우스를 올리면 큰 이미지 툴팁이 나타납니다. PSB 대조 분류 칩은 제거했습니다. 재출력 7종은 출력 필요, 시민 분절 네 묶음은 기존 재단 실물 재사용으로 완료입니다. 第2部 표지·完 마무리는 출력 대상에서 제외했습니다.

S12의 황혼빛/최종 결계 배경을 최신 PSB 두 레이어에 연결했습니다. S26 C01~C03은 C01 하나로 합치고 도입·마무리 모듈을 삭제해 2부62컷/통합112컷입니다. 에필로그는 주군과 낡은 각본집의 닫힘·펼침, 이름이 가득한 일기, CHA002-01-CU 조립 클로즈업과 새 아야메 대본을 사용합니다. 두 손은 CH-HANDS-01 치코링·CH-HANDS-02 에글랑틴이 접근하며, 황혼빛 아이와 모브는 출력 방향에서90도 세워 표시합니다. 준비물은 실제 화면 및 조립 구성품에 연결된101항목만 대조표에 남겼습니다. 새 서책·일기 작화는 Office PC PSB에 삽입·저장했습니다.

2026-11-23 책 닫힘·펼침을 세 쌍으로 대조했습니다. 치코링 일기는 청색 가죽과 작은 민무늬 모서리 보호구, 두께가 보이지 않는 정면 표지와 장식 없는 안쪽으로 통일했습니다. 어제·오늘 속지와 이름 페이지에는 작은 머리말과 여백을 넣었으며, 치코의 황토색 일기도 일기 형식으로 정리했습니다. 수정 스마트 레이어 5개와 어제·오늘 넘김을 PSB·로컬·공개 뷰어에 연결했습니다.

2026-11-24 S11에는 목공소 재집결을 넣고 네네링의 병원 창문 탈출과 쥬리땅의 목발 복귀를 나레이션으로 전달합니다. S13은 료의 전 회선 개방부터 쿠로코의 자재비 대사까지 일곱 인물의 개전 응답을 5컷으로 잇습니다. 중복된 쥬리땅의 확성기 대피 장면 S14·S17은 제거했습니다. 신규 소품 없이 기존 인물·배경·방벽을 재사용하며, 2부70컷/통합120컷입니다.

2026-11-24 고향 메이·치사와 벨, 이름표 NP028~NP030, 독립 씨앗 PR049·PR057을 실제 2부 PSB의 추가 A3 출력 시트에 배치했습니다. 뮤게 이름표 NP027과 새 이름표의 준비물 문구 목록도 보충했습니다. 교체된 일기·각본집 7항목을 현재 PSB 레이어에 다시 연결했으며, 대본·동작·영상은 유지했습니다. 등록된 필수 준비물의 PSB 미배치는 0건이고, 추가 8종의 실물 상태는 출력 필요입니다.
