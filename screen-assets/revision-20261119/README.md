# 2026-11-19 컷별 연출 수정 이미지

축음기·모브·가시·방벽·공통 계약서는 이후 [화풍 수정본](../style-20261119/README.md)으로 교체했습니다. 이 문서의 해당 항목은 이전 시안 이력입니다.

페이지에 연결한 경량 미리보기와 분리 출력 시안입니다. 기존 출력물과 새 작화 시안을 구분하며, 새 그림은 최종 재단·출력 확인 전입니다.

## 축음기

| 파일 | 상태 |
| --- | --- |
| phonograph-closed.webp | 상자 닫힘 |
| phonograph-open-empty.webp | 상자 열림·실린더 없음·태엽 없음 |
| phonograph-open-loaded.webp | 상자 열림·실린더 있음·태엽 없음 |
| phonograph-open-loaded-crank.webp | 상자 열림·실린더 있음·태엽 꽂힘 |
| component-cylinder.svg | 실린더 원통 |
| component-box.svg | 상자·축·기구 |
| component-lid.svg | 상자 뚜껑 |
| component-horn.svg | 작은 곡선 나팔 |
| component-crank.svg | 태엽 |

나팔 형태는 사용자가 제공한 [Edison Opera 실물 사진](https://www.technogallerie.com/shop/1912-edison-opera-cylinder-phonograph/)을 참고하여 작게 다시 그렸습니다. 사진의 로고·상표는 사용하지 않았습니다. 조립 상태는 같은 캔버스와 축척을 유지합니다. 분절 부품은 최종 조립 도안에서 위치와 크기를 맞춰 재단해야 합니다.

## 다른 그림

- `mob-group.webp`, `mob-black.svg`: 얼굴 없는 괴로운 동료 세 명을 한 장으로 묶은 그림과 동일 윤곽의 검은 뒷종이.
- `thorn-one-side.webp`: 한쪽 면에만 가시가 있는 줄기.
- `hands-before.webp`, `hands-clasped.webp`: 치코링·에글랑틴 손 인서트. 별도 클로즈업 규격.
- `contract-full.svg`, `contract-torn.svg`: 완전히 펼친 공통 원본과 마지막 해약 줄이 찢긴 초기 상태. `PR002_미서명_두루마리_손글씨_v2.png` 참고. 제목 아래 상세 조항을 넣고 싸인칸을 제거했습니다. 마지막 조항은 `해약`으로 시작합니다.
- `flowerless-background.webp`: 1부 꽃봉오리 그림에서 꽃·줄기·잎·가시를 모두 뺀 배경.
- `flower-bloom-clean.svg`, `flower-withered-clean.svg`: 1부 PR019 그림을 활용한 꽃 분리 시안. `flower-tear-*.svg`는 실제 한 장 찢기의 미리보기용 두 절반입니다.
- `earth-wall.webp`: 흙과 자갈로 세운 쿠로코의 방벽.
- `seed-black-marble.webp`: 검은 유리구슬 안 씨앗 하나. 같은 규격 다섯 개.
- `iris-closeup.webp`: 이리스 표정 인서트용 큰 그림.
- `garden-two-doors.webp`: 들어오는 문과 나가는 문이 모두 있는 새 정원 배경.
- `city-full-barrier.webp`: 사용자 지정 `BG-P02-S12-C01-01_도시전체결계_신규일러스트.png`의 경량 사본.
- `muguet.webp`: 기존 `CHB005-03_뮤게_마녀.png`의 경량 사본.
- `breakfast.webp`, `bread.webp`, `iris-flower.webp`, `iris-flower-bent.webp`: Office의 20261030 기존 일러스트를 해시 대조 후 재사용했습니다.
- `manuscript.svg`, `diary-epilogue.svg`, `diary-*.svg`: 기존 책과 대본의 일본어 글자를 조합한 각본집·일기 도안.

새 래스터 작화는 built-in image_gen을 사용했습니다. 글자, 검은 뒷종이, 찢기 절반, 부품 보기, 이펙트는 SVG로 구성합니다. 인쇄를 위해 SVG를 열 때는 연결 파일을 포함한 이 폴더 전체를 유지하세요.
