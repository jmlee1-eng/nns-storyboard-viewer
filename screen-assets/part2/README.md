# 2부 화면 구성 미리보기

2026-11-19 갱신. 준비물 목록에 연결된 원본의 경량 미리보기와 배치 설명용 SVG입니다. 인쇄용 원본 파일은 포함하지 않습니다.

- 공식 원본과 기존 가공 시안은 원본 SHA-256을 대조한 뒤 미리보기로 변환했습니다.
- 계약서·메모·가림판 등 SVG는 배치 설명용입니다. 최종 도안이나 출력 완료를 뜻하지 않습니다.
- 컷별 연결, 원본 경로, 준비 상태와 그림 종류는 `index.html`의 `viewerData`에서 관리합니다.
- 기존 출력물의 내장 이미지와 실측 크기는 유지합니다. 빈 뒷면 SVG는 종이를 뒤집는 동작 설명에 사용합니다.
